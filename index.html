Privacy-Preserving Speech Representation Unlearning

Selective Speaker Identity Unlearning in Self-Supervised Speech Models
View Source Code ↗

Modern self-supervised speech models like HuBERT encode both phonetic content and speaker identity in the same 768-dimensional hidden state. This creates a serious privacy risk — if a user revokes consent, their voice remains embedded in the model with no way to remove it short of full retraining (which costs thousands of dollars and weeks of GPU time).

This project implements Selective Speaker Identity Unlearning: a lightweight framework that surgically removes specific speakers from a trained model — without retraining from scratch, and without access to the original training data.

🚧 Key Barriers to Trustworthy RUL Prediction Addressed:

1. Sensor Noise & Drift

Multi-stage sensor noise masking early-stage engine degradation trends.

2. Operating Regime Shift

Up to 6 simultaneous flight regimes (altitude, Mach, throttle) altering baseline sensor norms.

3. Silent Evaluation Errors

Engine-level leakage or truncated test sets hiding flawed models behind good metrics.

4. Unknown Transferability

Lack of cross-regime transfer measurement across real-world diverse engine fleets.

💡 Technical Deep-Dive Finding:
Bidirectional reading helps ONLY on single-condition data (FD001: -7.4% RMSE reduction). On multi-condition data, operating regimes change WITHIN a 30-cycle window — the backward pass reads a different regime as 'future context', introducing noise rather than signal.
