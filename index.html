M.Tech Data Engineering Project

End-to-End Turbofan Engine Predictive Maintenance Engine

Medallion Data Lakehouse Architecture • Deep Learning RUL Estimation • Model Explainability

System Architecture Overview

⚡ 1. Ingestion (Bronze Layer)
  • Extracts NASA C-MAPSS raw multi-sensor engine simulation readings.
  • Converts raw unstructured text logs into highly efficient .parquet files.
  • Attaches schema definitions and operational run metadata.
🧹 2. Cleansing (Silver Layer)
  • Filters constant non-informative sensor columns.
  • Scales dynamic features using min-max bounds normalization.
  • Calculates piecewise linear target RUL curves for deep training models.
⚙️ 3. Feature Matrix (Gold Layer)
  • Constructs sequential 30-cycle time-series sliding window tensors.
  • Generates rolling temporal trend metrics and delta indicators.
  • Outputs serialized NumPy arrays prepared for neural network execution.
📊 4. Deep Learning & Dashboard
  • Stacked 2-layer LSTM network trained to evaluate failure curves.
  • Model explainability integration via SHAP values for diagnostic trust.
  • Interactive Streamlit dashboard displaying fleet health indexes and predictive maintenance alerts.
